LumaView is an image viewer and batch converter for **Apple Silicon Macs running macOS 14 or later**, inspired by IrfanView's workflow.

### Highlights

- Batch conversion and renaming with previews, presets and per-file results.
- Advanced resizing with resampling filters, cropping, rotation, color adjustments, text and watermarks.
- Format-specific export options beside Save As, shared with batch conversion.
- Adaptive monochrome TIFF conversion with CCITT Fax compression and explicit transparency handling.
- Multipage TIFF/PDF support, animated images, camera RAW input and local macOS OCR.
- Native Apple Silicon runtime, application icon and an illustrated guide.

The DMG and app ZIP include all required runtime dependencies. The source installer needs an internet connection. Intel Macs are not supported.

### First launch

The app is ad-hoc signed, without Apple Developer ID signing or notarization. If macOS blocks it as unverified, attempt to open it, then use **System Settings → Privacy & Security → Open Anyway**. [Apple's instructions](https://support.apple.com/102445).

### Notes

This is an early release. Editing is primarily 8-bit per channel. PDF/SVG input is rasterized; PDF export does not preserve original text or vector objects. PLD/PLB reads embedded previews. Windows plug-ins are not supported. See the [feature inventory](https://github.com/PianothShaveck/LumaView/blob/v0.1.2/docs/FEATURES.md) for details.

# Install LumaView

Requires macOS 14 or later and an Apple Silicon Mac.

1. Extract the complete installer ZIP.
2. Double-click **Install.command**.
3. Wait for **LumaView** to open.

The installer downloads Python and the required libraries into a private environment. An internet connection is required. No Homebrew, developer tools, administrator password or existing Python installation is needed.

If macOS blocks the installer as unverified, attempt to open it, then use **System Settings → Privacy & Security → Open Anyway**. See [Apple's instructions](https://support.apple.com/102445).

The app is installed in `~/Applications/LumaView.app`; its code and runtime are stored in `~/Library/Application Support/LumaView`. Run **Install.command** again to update or repair it. The extracted installer folder can be deleted after installation.

Press **B** for batch conversion. Open the illustrated guide from **Help**.

For a self-contained app that needs no dependency downloads, use the DMG or macOS app ZIP from [Releases](https://github.com/PianothShaveck/LumaView/releases/latest).
